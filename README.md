# Booking Platform

A multi-tenant appointment booking platform
that allows businesses to manage their services,
staff availability and customer appointments.

## Applications

- Backend
- Business Dashboard
- Embeddable Booking Widget

## Architecture

The project uses a monorepo structure.

All applications are maintained in one repository
but can be developed and deployed independently.
